# MYANMAR RECAP AI (မြန်မာ AI ဇာတ်လမ်းအကျဉ်း ချုပ်ဗီဒီယို ဖန်တီးစနစ်)

ဖုန်းဖြင့် အလွယ်တကူ အသုံးပြုနိုင်သော မြန်မာ AI ရုပ်ရှင်/ဇာတ်လမ်းအကျဉ်း ဗီဒီယို ဖန်တီးသည့် စနစ် (TikTok, YouTube Shorts, Reels အတွက် အထူးပြုလုပ်ထားသည်)။

---

## 📱 မိုဘိုင်းဖုန်းဖြင့် အသုံးပြုသူများအတွက် (Android Phone User Guide)

1. **ဗီဒီယိုတင်ရန် (Upload)**:
   - သင့်ဖုန်းထဲမှ ရုပ်ရှင်ဗီဒီယိုဖိုင် (MP4) ကို ရွေးချယ်ပါ သို့မဟုတ် "နမူနာဗီဒီယိုဖြင့် စမ်းသပ်မည်" ခလုတ်ကို နှိပ်၍ ချက်ချင်း စမ်းသပ်နိုင်ပါသည်။
2. **AI ဇာတ်ညွှန်းထုတ်ယူခြင်း (AI Script Generation)**:
   - ဇာတ်ကားခေါင်းစဉ်၊ လိုချင်သော စိတ်ခံစားမှုပုံစံ (အက်ရှင်၊ စိတ်လှုပ်ရှားဖွယ်၊ ဟာသ) နှင့် ကြာချိန်ကို ရွေးချယ်ပြီး Gemini AI ဖြင့် စကားပြောသဘာဝအတိုင်း ဇာတ်လမ်းပြောစာသား ထုတ်ယူပါ။
3. **မြန်မာအသံ ရွေးချယ်ခြင်း (AI Voiceover)**:
   - မြန်မာအမျိုးသမီးသံ (Nilar / ချိုသာကြည်လင်) သို့မဟုတ် မြန်မာအမျိုးသားသံ (Thiha / တည်ကြည်အားမာန်) ကို ရွေးချယ်ပြီး အသံအမြန်နှုန်း၊ မူရင်းဗီဒီယိုအသံ ပိတ်/ဖွင့် ချိန်ညှိပါ။
4. **မြန်မာစာတန်းထိုးနှင့် မူရင်းစာတန်းဝါးခြင်း (Subtitles & Text Blur)**:
   - အဝါရောင်၊ အဖြူရောင် မြန်မာစာတန်းထိုးဒီဇိုင်းများ၊ Padauk/Pyidaungsu font ဖြင့် ထည့်သွင်းပါ။
   - မူရင်း ဗီဒီယိုပေါ်ရှိ အင်္ဂလိပ်/တရုတ် စာတန်းဟောင်းများနှင့် Watermark များကို ဖုန်း screen ပေါ်တွင် လက်ဖြင့် အကွက်ရွှေ့၍ အလွယ်တကူ ဝါးပစ်နိုင်ပါသည်။
5. **ဗီဒီယို ထုတ်ယူခြင်း (Video Export)**:
   - 9:16 (TikTok/Shorts), 16:9 (YouTube), 1:1 (Instagram) ဘောင်များကို ရွေးချယ်ပြီး သင့်ဖုန်းထဲသို့ MP4 ဗီဒီယိုအဖြစ် တိုက်ရိုက်ဒေါင်းလုဒ်ရယူပါ။
6. **Pro Tool & WavePay**:
   - အကန့်အသတ်မရှိ HD အရည်အသွေးထုတ်ယူရန် WavePay အမှတ် `09797879485` သို့ လွှဲပြောင်း၍ Transaction ID ဖြင့် အတည်ပြုနိုင်ပါသည်။
